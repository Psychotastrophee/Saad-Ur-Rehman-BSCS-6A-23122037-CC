## 📌 Project Overview
This repository contains a **Lexical Analyzer (Lexer)** developed using **FLEX (Fast Lexical Analyzer Generator)** as part of the Compiler Construction course. 

The lexer scans source code files, identifies lexical tokens, categorizes them into distinct groups, handles errors (such as unterminated strings or comments), and prints out an organized token table along with a full summary of token counts.

---

## 🛠️ Token Categories Recognized
The lexer recognizes and classifies the following token categories:

* **Keywords:** `if`, `else`, `int`, `return`, `while`, `for`, `float`, `char`, etc.
* **Identifiers:** Variable names and function names starting with a letter or underscore.
* **Literals:**
  * **Integers:** Whole numbers (e.g., `10`, `20`).
  * **Floats:** Decimal values (e.g., `20.5`).
  * **Strings:** Text inside double quotes (e.g., `"x is smaller"`).
  * **Characters:** Single characters inside single quotes.
* **Operators:**
  * **Relational / Comparison:** `<=`, `>=`, `==`, `!=`, `<`, `>`
  * **Arithmetic / Assignment:** `=`, `+`, `-`, `*`, `/`, `%`
* **Symbols & Delimiters:** Semi-colons `;`, parentheses `()`, curly braces `{}`.
* **Preprocessor Directives:** `#include`, `#define`, etc.

---

## 📁 Repository Structure
* **`lexer.l`**: The primary FLEX source specification file containing regular expressions and scanner rules.
* **`input.txt`**: Sample input code written to test token recognition, specifically verifying `int`, `if`, and `else` keywords.
* **`lex.yy.c`**: Scanner C source code generated by FLEX.
* **`output_2.txt`**: Output file capturing token categorization and the final summary table.
* **`Output.png`**: Screenshot of command-line execution verifying output accuracy.

## 🚀 How to Run

### Prerequisites
* **FLEX** (or `win_flex` on Windows)
* **GCC / MinGW** C Compiler

### Compilation & Execution Steps

1. **Generate C code from FLEX specification:**

```C
   flex lexer.l
```

```C
   gcc lex.yy.c
```

```C
   lex.yy.exe input.txt
```

```C
   lex.yy.exe input.txt > output.txt
```
